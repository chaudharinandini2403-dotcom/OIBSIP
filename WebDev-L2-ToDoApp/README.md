
A simple to-do list web app built with HTML, CSS, and JavaScript.

- `index.html` - App structure and UI.
- `style.css` - App styling.
- `app.js` - App behavior and interaction logic.

1. Open `index.html` in your browser.
2. Add new tasks, mark them complete, and remove tasks as needed.


This project is a lightweight front-end app for managing a to-do list. It is intended for learning and quick task management demos.
