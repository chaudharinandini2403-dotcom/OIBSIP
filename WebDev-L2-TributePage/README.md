# 🚀 Tribute to Dr. A.P.J. Abdul Kalam — The People's President

A premium, highly interactive, and responsive tribute webpage dedicated to the life, scientific contributions, presidential tenure, and everlasting legacy of **Dr. A.P.J. Abdul Kalam**, the *Missile Man of India*.

Designed with a modern, cosmic-themed dark aesthetic, this landing page serves as an immersive digital biography, capturing the essence of his vision and teachings.

---

## ✨ Features

- **Cosmic Dark Mode Aesthetic**: Visual design featuring curated space-inspired colors (Saffron, Gold, Deep Blue) representing science and exploration.
- **Dynamic Particle System**: Built-in vanilla JS space/spark background particles in the hero section that simulate starry ascents.
- **Smooth Parallax Effect**: Parallax scrolling in the main hero section to elevate the landing experience.
- **Scroll-Triggered Animations**: Content cards, timeline entries, and quote blocks gracefully reveal themselves on scroll utilizing the modern `IntersectionObserver` API.
- **Milestones Timeline**: A beautifully animated central timeline outlining his journey from a modest background in Rameswaram (1931) to his last lecture in Shillong (2015).
- **Interactive Publications Grid**: A visual collection of books and written works by Dr. Kalam (such as *Wings of Fire* and *Ignited Minds*) designed as hover-responsive deck cards.
- **Fully Responsive Structure**: Fluid grid systems and media queries tailored for smartphones, tablets, and desktop displays.

---

## 🛠️ Technology Stack

- **Markup**: Semantic HTML5 structures for improved web compliance and SEO optimization.
- **Styles**: Custom CSS3 utilizing CSS Custom Properties (Variables), CSS Grid, Flexbox, custom gradients, and keyframe animations.
- **Behavior**: Lightweight, pure Vanilla JavaScript (zero external dependencies/frameworks) for animations and scroll logic.
- **Typography**: Google Fonts integration:
  - `Playfair Display` (Classic serif for headings)
  - `Inter` (Sleek sans-serif for comfortable reading)
  - `Cormorant Garamond` (Elegant serif for block quotes)

> [!NOTE]
> Ensure the image files (`abdul kalam.jpg`, `rocket.png`, `divider.png`) match the paths specified in your version of `index.html`. If they are located directly in the root directory, update your image `src` attributes accordingly (e.g. from `Images/abdul kalam.jpg` to `abdul kalam.jpg`).

## 🚀 Getting Started

To run this project locally, follow these simple steps:

1. **Clone or Download the Project**:
   Save all directory files into a local folder on your computer.

2. **Open index.html**:
   Double-click the `index.html` file to open it directly in web browsers (Chrome, Edge, Firefox, Safari) or use a local development server extension in your editor (e.g., Live Server in VS Code).
